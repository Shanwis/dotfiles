# Dotfiles

Personal Linux development environment configuration files.

I am currently running **Fedora Linux** with **[niri](https://github.com/YaLTeR/niri)** as my scrollable tiling Wayland compositor and **[DankMaterialShell](https://github.com/AvengeMedia/DankMaterialShell)** as my desktop shell.

* **OS:** Fedora Linux
* **Window Manager:** Niri (Wayland)
* **Desktop Shell:** DankMaterialShell (DMS)
* **Terminal Emulator:** Alacritty *(considering Ghostty in the future)*
* **Shell:** Bash *(considering Zsh or Fish in the future)* + Starship prompt + Atuin + Zoxide
* **Terminal Multiplexer:** tmux (managed via TPM, themed with Catppuccin Mocha)
* **Editor:** Neovim (Kickstart.nvim based) & OpenCode
* **File Manager:** Yazi (+ dragon for drag-and-drop)
* **Document Viewer:** Zathura
* **Notes:** Obsidian (with AnuPpuccin theme & curated plugins)
* **Theme & Appearance:** Catppuccin Mocha & Material You dynamic colors
* **Font:** JetBrainsMono Nerd Font

## Tools & Highlights

### Window Manager & Shell (Niri + DankMaterialShell)
- **Niri:** Scrollable tiling Wayland compositor configured with custom binds, layout overrides, window rules, and multi-monitor output handling.
- **DankMaterialShell (DMS):** Material You desktop shell providing panel, widgets, notifications, dynamic wallpaper blur, and IPC integration (e.g. `Mod+P` for DMS power menu).
- **Firefox Integration:** Includes `DankMaterialShell/firefox.css` for matching Material You styling in Firefox via `userChrome.css`.

### Terminal & Multiplexer (Alacritty + tmux)
- **Alacritty:** Borderless terminal with JetBrainsMono Nerd Font (size 12), customized padding, and clipboard auto-copy. Imports the Catppuccin Mocha theme or DMS dynamic colors.
- **tmux:**
  - Status bar styled with Catppuccin Mocha showing session, active command, path, window zoom flag, battery percentage, online/offline status, and clock.
  - Vi-mode keys for navigation (`h`, `j`, `k`, `l`).
  - Automatic TPM (Tmux Plugin Manager) bootstrapping on first run.
  - **Fuzzy Session Creator (`tmux-new.sh`):** Uses `fd` and `fzf` to quickly search directories across `$HOME` and `/mnt/Data` to attach or create a named tmux session.

### Shell & Productivity (Bash + Starship + Atuin + Zoxide)
- **Starship Prompt:** Multi-segment colored prompt with Catppuccin Mocha palette displaying OS symbol, user, directory, git branch/status, language runtimes, command duration, and timestamp.
- **Atuin:** Synchronized SQLite shell history with fuzzy daemon search mode (`daemon-fuzzy`) and Vim-style normal keybindings (`vim-normal`).
- **Zoxide:** Smarter `cd` directory jumper initialized directly in `.bashrc`.
- **Functions:** Includes `homelab` in `.bashrc` which automatically checks local network reachability before deciding whether to connect via local LAN SSH or Tailscale.

### File Management & Viewers (Yazi + Zathura)
- **Yazi:** Blazing fast TUI file manager with Catppuccin Mocha flavor, hidden files visible by default, and custom bindings:
  - `<Ctrl-n>`: Initiates drag-and-drop for the hovered file via [dragon](https://github.com/mwh/dragon).
  - `!`: Spawns a subshell in the current working directory.
- **Zathura:** Lightweight document/PDF viewer with clipboard selection sync, automatic width adjustment, basename window titles, and Catppuccin Mocha theming.

### AI Agents & Skills (`agents/`)
- AI coding workflows (such as OpenCode) are supported with reusable agent skills managed under `agents/skills/`:
  - `caveman`: Simplified communication mode for agents.
  - `find-skills`: Discovery tool for discovering and installing agent skills.
  - `webapp-testing`: End-to-end webapp testing utilities.
  - `agent-browser`: Browser automation capabilities.
  - `frontend-design`: UI/UX design guidance for agent tasks.

### Obsidian
- Includes full `.obsidian` configuration with AnuPpuccin theme and popular community plugins: Dataview, Tasks, QuickAdd, Calendar, and Homepage.
- Provides `sync.sh` to mirror settings from your live vault into the dotfiles repository.

### GRUB Bootloader
- Themed with the [Fallout GRUB theme](https://github.com/shvchk/fallout-grub-theme).
- Includes `shorten-grub-entries` to clean up default Fedora boot entries in `/boot/loader/entries/`, renaming the latest kernel to `Fedora <version> (Latest)` and older kernels to `Fedora <version> (Old)`.

## Setup & Installation

### Prerequisites

Ensure the following tools and packages are installed on your system (Fedora packages shown where applicable):

```bash
# Core tools and terminal utilities
sudo dnf install -y alacritty tmux starship zoxide fzf fd-find yazi zathura zathura-pdf-mupdf rsync

# Optional utilities
# dragon (for Yazi drag-and-drop): https://github.com/mwh/dragon
# Atuin: https://github.com/atuinsh/atuin
# JetBrainsMono Nerd Font: https://www.nerdfonts.com/
```

### 1. Clone the Repository

```bash
git clone https://github.com/Shanwis/dotfiles.git ~/Data/PROJECTS/dotfiles
cd ~/Data/PROJECTS/dotfiles
```

### 2. Automated Bootstrap (Recommended)

Run the automated bootstrap script. It will create missing destination directories, safely backup any conflicting configurations (with a `.backup.<timestamp>` suffix), create symlinks, and grant execution permissions to helper scripts:

```bash
chmod +x setup.sh
./setup.sh
```

---

### 3. Manual Setup (Alternative)

If you prefer to link individual components manually:

```bash
# Ensure target directories exist
mkdir -p ~/.config ~/.local/bin ~/.config/atuin

# Shell & Core Tools
ln -s ~/Data/PROJECTS/dotfiles/bash/.bashrc ~/.bashrc
ln -s ~/Data/PROJECTS/dotfiles/alacritty ~/.config/alacritty
ln -s ~/Data/PROJECTS/dotfiles/starship/starship.toml ~/.config/starship.toml
ln -s ~/Data/PROJECTS/dotfiles/atuin/config.toml ~/.config/atuin/config.toml

# Window Manager & Desktop
ln -s ~/Data/PROJECTS/dotfiles/niri ~/.config/niri
ln -s ~/Data/PROJECTS/dotfiles/DankMaterialShell ~/.config/DankMaterialShell

# Multiplexer & CLI Tools
ln -s ~/Data/PROJECTS/dotfiles/tmux/.tmux.conf ~/.tmux.conf
ln -s ~/Data/PROJECTS/dotfiles/tmux/tmux-new.sh ~/.local/bin/tmux-new.sh
ln -s ~/Data/PROJECTS/dotfiles/nvim ~/.config/nvim
ln -s ~/Data/PROJECTS/dotfiles/yazi ~/.config/yazi
ln -s ~/Data/PROJECTS/dotfiles/zathura ~/.config/zathura

chmod +x ~/Data/PROJECTS/dotfiles/tmux/tmux-new.sh
chmod +x ~/Data/PROJECTS/dotfiles/obsidian/sync.sh
chmod +x ~/Data/PROJECTS/dotfiles/grub/shorten-grub-entries
```

## Component-Specific Instructions

### tmux Plugins (TPM)
TPM is automatically cloned and installed when launching tmux with this config.
To manually install or refresh plugins inside tmux, press:
```text
prefix + I   (default prefix is Ctrl+b)
```

### Obsidian Configuration Backup & Sync
To backup and sync settings from an active Obsidian vault into the repository:

```bash
cd ~/Data/PROJECTS/dotfiles/obsidian
./sync.sh <vault-name>
```

> **Note:** The script expects your vault to reside under `~/Data/obsidian/<vault-name>/`. It automatically syncs `.obsidian/` while excluding workspace state files (`workspace.json`).
>
> If `~/Applications/Obsidian-*.AppImage` exists on your system, `setup.sh` will also automatically symlink it to `~/.local/bin/obsidian-app`.

### GRUB Fallout Theme & Shorten Entries
To install the Fallout GRUB theme:

```bash
git clone https://github.com/shvchk/fallout-grub-theme.git
cd fallout-grub-theme
sudo ./install.sh
```

To apply the custom GRUB settings:

```bash
sudo cp ~/Data/PROJECTS/dotfiles/grub/default-grub /etc/default/grub
sudo grub2-mkconfig -o /boot/grub2/grub.cfg
```

To clean up verbose Fedora kernel entries in `/boot/loader/entries/`:

```bash
sudo ~/Data/PROJECTS/dotfiles/grub/shorten-grub-entries
```
